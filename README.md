# 🎯 Gains Ledger - Progressive Web App

A comprehensive nutrition tracking and personal finance management app that works on any device, online or offline.

## ✨ Features

### 💪 Nutrition Tracking
- 14-day meal rotation plan
- 5 meals per day (breakfast, lunch, pre-workout, post-workout, dinner)
- Macro tracking (protein, carbs, fats, fiber)
- Exercise logging with calorie burn
- Interactive calendar view

### 💰 Finance Management
- Income/salary tracking
- Expense categorization
- Investment management with interest calculations
- Stock portfolio tracking
- Financial visualizations and analytics
- Income vs Expense charts
- Category breakdown by donut charts

### 🔔 Smart Notifications
- Meal reminders 1 hour before each meal
- Customizable per meal type
- Works offline and online
- Sound and vibration support

### 🔊 Text-to-Speech
- Hear meal details spoken aloud
- Works offline
- Works on iOS and Android

### 📱 Progressive Web App
- Install on home screen (iOS/Android)
- Works completely offline
- Automatic updates
- No app store needed
- Works like native app

### 🔒 Privacy & Security
- All data stored locally on device
- No cloud storage
- No data sharing
- User-specific isolation

## 🚀 Quick Start

### Installation

#### iOS (iPhone/iPad)
1. Open Safari
2. Go to your hosted domain
3. Tap Share → "Add to Home Screen"
4. App appears on home screen
5. Open app like any native app

#### Android (Chrome/Firefox)
1. Open Chrome or Firefox
2. Go to your hosted domain
3. Tap menu → "Install app"
4. Confirm installation
5. App appears on home screen
